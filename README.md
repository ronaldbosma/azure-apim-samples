# Azure API Management Samples

This repository contains various samples for Azure API Management.

- [Catch-All API](catch-all-api/README.md): A sample API that catches all HTTP methods and forwards them to a backend service.
- [Convert Base64 to multipart/form-data](base64-to-multipart-formdata/README.md): A sample that converts a Base64 encoded file to a multipart/form-data request.
