# Convert Base64 to multipart/form-data

A sample that converts a Base64 encoded file in a JSON request to a multipart/form-data request. 
It sends the request to an Azure Function that processes the file and returns it as a downloadable file.

See the blog post [Convert Base64 to multipart/form-data with API Management](https://ronaldbosma.github.io/blog/2025/09/04/convert-base64-to-multipart/form-data-with-api-management/) for more details.
